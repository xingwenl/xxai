# 智能体管理规格

## 目标

- 为当前登录用户提供平台列表和平台内智能体管理。
- 支持智能体创建、编辑、启用/停用、硬删除。
- 支持智能体版本列表、创建版本、发布版本和回滚版本。
- API Key 由后端加密保存，前端只发送新增版本时输入的密钥，列表和版本响应不返回明文。

## 范围

### 后端

- `GET /api/v1/platforms`：返回当前用户可管理的平台。
- `GET /api/v1/platforms/{platform_id}/agents`：返回平台内智能体列表。
- `POST /api/v1/platforms/{platform_id}/agents`：创建智能体。
- `PATCH /api/v1/platforms/{platform_id}/agents/{agent_id}`：修改名称、slug、描述和 `is_active`。
- `DELETE /api/v1/platforms/{platform_id}/agents/{agent_id}`：硬删除智能体，版本由数据库级联删除。
- `GET /api/v1/platforms/{platform_id}/agents/{agent_id}/versions`：返回版本元数据。
- 保留已有版本创建、发布和回滚接口。
- `agents` 表新增 `is_active` 字段及迁移。

### 前端

- 新增 `src/api/platform.ts`、`src/api/agent.ts`。
- 新增 `/ai/bots` 路由和 `features/agents` 页面。
- 页面提供平台选择、智能体列表、编辑/删除/状态操作和版本管理对话框。

## 非目标

- 不实现平台创建、平台编辑或平台删除。
- 不回显 API Key，不提供 API Key 查看功能。
- 不新增角色权限模型；后端沿用当前平台管理员校验。
- 不修改知识库、技能和 MCP 管理页面。

## 风险

- 硬删除不可恢复，页面必须二次确认；数据库依赖版本外键级联。
- 平台管理员校验失败时，后端返回资源不存在语义，前端展示统一错误。
- 当前前端全量构建已有依赖基线问题，需执行变更文件检查和后端定向测试。

## 停点判断

- 架构边界变化：否，沿用现有模块分层。
- 数据模型变化：是，新增 `agents.is_active`。
- API 契约变化：是，新增平台/智能体/版本列表及 CRUD 接口。
- 鉴权或权限行为变化：否，复用现有平台管理员校验。
- 人工确认：已于 2026-07-29 获得确认。

## 验收标准

- 后端 OpenAPI 暴露平台列表、智能体列表、更新、删除、版本列表接口。
- 未授权用户不能访问平台或智能体管理接口。
- 智能体硬删除后，其版本记录一并删除。
- 前端可以选择平台并完成智能体 CRUD、停用/启用和版本发布/回滚。
- API Key 不出现在任何列表响应或前端展示中。
- 后端定向测试、ruff 检查、前端变更文件 ESLint/Prettier 通过。
