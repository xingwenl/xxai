# 智能体详情工作台设计说明

## 目标

- 将当前“智能体列表 + 多个配置弹窗”优化为“列表 + 独立详情工作台”。
- 让平台管理员在单个智能体上下文中查看状态、编辑配置、管理知识库/技能/工具关联、管理版本并查询当前智能体用量。
- 所有关联资源均支持关联与解除关联，变更在智能体下一轮对话中生效。
- 复用 `research.md` 确定的标签式工作台方案与现有运行时、用量事实表，不引入新的统计数据源或工具权限模型。

## 用户与页面任务

- 目标用户：管理平台智能体配置和运行情况的平台管理员。
- 页面单一任务：围绕一个智能体完成配置、能力和用量管理。
- 成功结果：用户无需在多个独立管理页和弹窗间来回切换，即可判断智能体是否可用、具备哪些能力、当前使用哪个版本以及近期消耗多少模型 Token。

## 页面架构

### 智能体列表

- 保留 `/ai/bots` 作为列表入口。
- 增加名称/Slug 搜索、启用状态筛选和进入详情操作。
- 创建智能体仍从列表发起；创建成功后可进入新智能体详情。
- 版本、工具等跨模块配置不再继续堆叠为列表行内弹窗。

### 智能体详情

- 新增 `/ai/bots/:agentId` 路由，默认展示概览。
- 一级标签写入 URL，可刷新和直达：`概览 / 配置 / 知识库 / 技能 / 工具 / 版本 / 用量`。
- 页面头部常驻返回列表、名称、Slug、启停状态、当前发布版本、模型和常用操作。
- 删除智能体位于配置页底部危险操作区，继续使用二次确认。
- 小屏下标签支持横向滚动，头部操作收敛到菜单，不允许文字或控件重叠。

## 概览

- 状态摘要：启用状态、当前版本、模型、最近发布时间。
- 能力摘要：已关联知识库、技能、内置工具、MCP 有效工具和宿主工具数量。
- 用量摘要：近 7 天调用次数、输入 Token、输出 Token、总 Token及相对前 7 天变化。
- 趋势：近 7 天每日总 Token。
- 配置完整性：未发布版本、未配置模型密钥、未关联任何能力等可由真实数据判断的问题。
- 最近活动首期只展示已有可靠事件；没有统一活动数据时不拼接或伪造配置审计。

## 配置与版本

- 配置页编辑名称、描述和启用状态；Slug 创建后只读。
- 当前模型配置只读展示。
- 修改模型、系统提示词、温度或 API Key 时创建新版本，发布后生效。
- 版本页承接现有版本列表、新建、发布和回滚能力，并明确标注当前版本。
- 页面明确区分两类生效语义：基本信息与能力关联实时生效；模型与提示词随版本发布生效。

## 关联管理

### 通用交互

- 每个关联标签包含已关联数量、搜索、状态筛选和紧凑列表。
- 每行使用关联开关；开启执行关联，关闭执行解除关联。
- 变更只锁定当前行；成功后更新列表和概览计数，失败后恢复开关并显示错误。
- 固定提示“关联变更将在智能体下一轮对话中生效”。
- 已停用或不可用资源继续展示并标注原因。

### 知识库

- 展示名称、文档数量或可用状态、Embedding 模型和索引状态。
- 支持关联与解除关联。
- 新增按智能体查询知识库关联和解除关联接口；关联复用现有接口。

### 技能

- 展示名称、描述、启用状态、是否来自技能包及是否包含脚本能力。
- 支持关联与解除关联，复用现有按智能体技能接口。

### 工具

- 工具一级标签内包含 `内置工具 / MCP 工具 / 宿主工具` 三个子标签。
- 内置工具按具体工具关联或解除关联，展示名称、描述和副作用级别。
- 宿主工具按具体工具关联或解除关联，展示副作用级别和确认策略。
- MCP 沿用当前 `AgentMcpServer` 模型，按 MCP 服务关联或解除关联；展开服务后显示实际可用工具、允许状态和副作用级别。
- MCP 工具允许状态与副作用策略仍在 MCP 管理页维护，详情页不改变全局策略。

## 用量

- 提供 `近 7 天 / 近 30 天` 分段切换。
- 展示调用次数、输入 Token、输出 Token和总 Token，并与上一周期比较。
- 按日期展示 Token 趋势及输入/输出构成。
- 展示最近 10 条调用明细：时间、模型、会话、请求 ID、输入/输出/总 Token。
- 提供跳转现有完整模型用量页的入口，并携带当前平台和智能体筛选。
- 不展示费用；当前数据没有模型价格快照，不能可靠反算历史费用。

## 接口设计

### 新增接口

- `GET /api/v1/platforms/{platform_id}/agents/{agent_id}`：读取当前平台内的智能体详情。
- `GET /api/v1/platforms/{platform_id}/agents/{agent_id}/knowledge-bases`：读取当前智能体的知识库关联。
- `DELETE /api/v1/platforms/{platform_id}/agents/{agent_id}/knowledge-bases/{base_id}`：解除知识库关联。

### 复用接口

- 关联知识库继续使用 `PUT /api/v1/platforms/{platform_id}/knowledge-bases/{base_id}/agents/{agent_id}`。
- 技能、MCP 服务、宿主工具和内置工具复用现有按智能体查询与变更接口。
- 用量复用现有明细与汇总接口，并固定传入当前 `agent_id` 和日期范围。

### 契约语义

- 所有详情和关联接口继续执行平台管理员校验，跨平台资源使用资源不存在语义。
- 重复关联保持幂等；解除不存在的关联返回稳定的资源不存在错误。
- 响应不回显模型 API Key、Embedding API Key、MCP 认证头或其他密钥。

## 数据流与状态

1. 详情路由从 URL 获取 `agentId`，结合当前平台加载智能体详情。
2. 每个标签按需加载自身数据，单标签失败不阻塞页面头部和其他标签。
3. 关联 mutation 成功后精确失效当前能力查询和概览摘要查询。
4. 切换平台时返回智能体列表，避免保留不属于新平台的详情 URL。
5. 用量按当前智能体与时间范围查询，趋势和周期对比由现有按日汇总结果计算。

## 加载、空状态与错误

- 首次加载使用固定尺寸骨架，避免页面布局跳动。
- 单标签错误展示明确原因和重试按钮。
- 没有关联资源时提供关联操作，不使用仅有说明文字的空白页。
- 智能体不存在或无权访问时展示资源不存在页。
- 关联变更失败时恢复当前行状态，不回滚其他已成功操作。

## 视觉方向

- 延续现有 shadcn 管理后台的中性色、字体、紧凑表格和 8px 以内圆角。
- 页面定位为高频运营工具，不使用营销式 Hero、装饰性渐变或大面积卡片堆叠。
- 唯一强调元素是详情头部的“运行状态带”：用状态、当前版本和实时生效提示形成稳定识别区；其余区域保持克制。
- 概览指标使用无嵌套的紧凑统计区；关联资源使用列表或表格，不在卡片中继续嵌套卡片。
- 图标使用现有 Lucide 图标并提供必要 Tooltip；数字和固定格式控件使用稳定宽度。

## 范围

### 前端

- 重构 `apps/front/src/features/agents/`，拆分列表、详情布局、各标签和共享关联组件。
- 扩展 `apps/front/src/api/agent.ts` 与 `knowledge.ts`。
- 新增智能体详情路由并支持标签 URL 状态。
- 调整现有模型用量页以接收 URL 中的平台和智能体筛选参数。

### 后端

- 在智能体模块新增详情读取接口。
- 在知识库模块新增按智能体查询关联和解除关联接口。
- 补充平台隔离、幂等关联、解除关联和资源不存在测试。

## 非目标

- 不新增或修改数据库表。
- 不将知识库、技能和工具关联纳入智能体版本。
- 不支持单个 MCP 工具与智能体的独立关联。
- 不在智能体详情中编辑 MCP 全局工具策略。
- 不实现统一配置变更审计或虚构“最近活动”。
- 不计算模型费用，不修改现有计费口径。
- 不修改现有平台管理员权限语义。

## 风险

- 多标签聚合容易产生重复查询，必须通过按需加载和精确 query key 控制。
- 能力关联实时生效，错误提示必须明确，避免用户把全局资源停用误认为关联丢失。
- MCP 服务关联和工具级展示存在粒度差异，界面必须明确“关联的是服务，可用工具受全局策略控制”。
- 当前前端历史上存在全量构建依赖基线问题，仍需优先执行变更文件检查，并记录真实全量验证结果。

## 停点判断

- 架构边界变化：否，继续使用现有前后端模块和路由体系。
- 数据模型变化：否。
- API 契约变化：是，新增智能体详情、知识库关联查询和解除关联接口。
- 鉴权或权限行为变化：否，继续使用平台管理员校验。
- 人工确认：进入实现前必须确认新增 API 契约及其幂等/错误语义。

## 验收标准

- 用户可从智能体列表进入独立详情页，并通过 URL 直达七个一级标签。
- 页面头部正确展示智能体状态、当前版本和模型；小屏无重叠。
- 知识库、技能、内置工具、MCP 服务和宿主工具均可关联和解除关联。
- MCP 页面明确按服务关联，并能查看服务内有效工具及策略状态。
- 关联成功后概览计数同步更新，失败时当前行恢复且错误可理解。
- 用量页可切换近 7/30 天，展示四项指标、趋势、周期变化和最近 10 条明细。
- 完整用量入口携带当前平台和智能体筛选。
- 跨平台访问被后端拒绝，任何响应不回显密钥。
- 后端定向测试、前端变更文件 ESLint/Prettier、类型检查和可运行环境下的桌面/移动浏览器验证均有真实记录。
