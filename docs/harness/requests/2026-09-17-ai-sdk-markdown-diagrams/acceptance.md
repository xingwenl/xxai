## 剩余风险

- **真实引擎未验证**：本次以假引擎验证装配与生命周期，mermaid / echarts 真实渲染效果、主题配色、不同图类型的兼容性需要接入方在联网环境补一次人工确认。
- **浏览器引擎级验证缺失**：headless Chrome 在本环境不可用，jsdom 覆盖不到真实 SVG 布局与 `ResizeObserver` 行为，建议在有图形界面的环境打开 `apps/ai-sdk/demo/` 做一次人工回归。
- **主题切换限制**：图表主题在挂载时确定，切换 `.dark` 类或系统主题后需消息重渲染才更新配色，已在 README「已知限制」中标注。
- **引擎安全责任边界**：SDK 提供三层清洗（strict 配置 + 指令剔除 + SVG 二次清洗），但不修复引擎自身漏洞；接入方需自行保持引擎版本更新。
- **`package-lock.json` 待同步**：新增 `devDependencies.jsdom` 需要联网 `npm install` 生成锁文件，否则 CI/他人本地运行 DOM 用例会缺依赖。
