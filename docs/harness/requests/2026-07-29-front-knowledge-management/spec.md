# 知识库管理规格

## 目标

- 为当前登录用户提供平台内知识库和文档的真实管理页面。
- 支持知识库创建、编辑、硬删除，以及文件/URL 文档的添加、查看、删除和失败重试。
- 复用现有异步入库、切分和向量化任务，不在管理请求中同步执行耗时处理。
- 依据 `research.md` 的结论，统一使用平台级 API，不再依赖前端旧 `/api/...` 接口。

## 范围

### 后端

- `GET /api/v1/platforms/{platform_id}/knowledge-bases`：返回平台知识库列表。
- 保留 `POST /api/v1/platforms/{platform_id}/knowledge-bases` 和 `PATCH /{base_id}`。
- `DELETE /api/v1/platforms/{platform_id}/knowledge-bases/{base_id}`：硬删除知识库及级联数据。
- `GET /api/v1/platforms/{platform_id}/knowledge-bases/{base_id}/documents`：返回文档列表。
- 保留文件上传、URL 添加和文档详情接口。
- `DELETE /.../{base_id}/documents/{document_id}`：硬删除文档及其切片/任务。
- `POST /.../{base_id}/documents/{document_id}/retry`：仅允许失败文档重新排队入库。
- 所有管理接口复用当前用户和平台管理员校验。
- API 响应不返回 embedding API Key 明文，仅返回 `has_embedding_api_key`。

### 前端

- 新增平台选择和知识库列表页面，挂载现有 `/ai/knowledge-bases` 导航。
- 提供知识库创建/编辑表单、删除二次确认。
- 提供选中知识库的文档列表、文件上传、URL 添加、删除和失败重试。
- 提供知识库绑定智能体入口，允许在知识库页面直接选择智能体并调用现有绑定接口。
- 使用 TanStack Query 管理查询和 mutation，变更后失效对应平台/知识库 query。
- 将 `src/api/knowledge.ts` 改为真实 `/platforms/{platform_id}/...` 契约，移除旧路径调用。

## 非目标

- 不新增独立文本条目模型或文本条目 API；旧前端文本条目方法本次移除或不接入。
- 不修改向量检索算法、embedding runtime、Celery broker 或存储基础设施。
- 不实现平台创建、平台编辑、平台删除。
- 不提供 API Key 查看、解密或回显能力。
- 不在本次前端范围内新增绑定状态列表或解绑入口；先复用现有绑定 API 完成最小可用功能。
- 不在本 request 同时改造技能和 MCP 页面；它们另建 request 继续推进。

## 风险

- 硬删除不可恢复，知识库和文档页面必须二次确认。
- 文档删除涉及数据库级联和本地上传文件清理，需避免留下无主文件。
- 重试接口必须限制在 `failed` 状态，避免重复调度正在处理的任务。
- 现有前端全量构建存在依赖基线错误，需保留并区分本次文件级检查结果。

## 停点判断

- 架构边界变化：否，沿用现有 knowledge/platform 分层。
- 数据模型变化：否，优先复用现有表结构和级联外键。
- API 契约变化：是，新增列表、删除、文档列表、文档删除和重试接口。
- 鉴权或权限行为变化：否，复用平台管理员校验。
- 人工确认：是，进入实现前需确认新增 API 和硬删除语义。

## 验收标准

- 后端 OpenAPI 暴露知识库列表、知识库删除、文档列表、文档删除和文档重试接口。
- 非平台管理员不能访问平台内知识库和文档管理接口。
- 知识库硬删除后，关联文档、切片和摄取任务不再可查询。
- 失败文档可以重新排队；非失败文档不能重复重试。
- 前端可以选择平台、完成知识库 CRUD，并完成文档上传/URL 添加/删除/失败重试。
- 前端可以从知识库页面直接绑定一个智能体到当前知识库。
- 前端及接口响应不展示 embedding API Key 明文。
- 后端定向 pytest/ruff、前端变更文件 ESLint/Prettier 通过。
