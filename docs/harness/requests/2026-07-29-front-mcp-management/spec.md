# MCP 服务管理规格

## 目标

- 为当前登录用户提供平台内远程 MCP 服务配置和运行策略管理。
- 支持服务创建、编辑、启用/停用、审计保护删除、工具同步和工具策略编辑。
- 支持服务绑定/解绑智能体，并查看平台最近调用审计。
- 保留认证头加密存储、SSRF 防护、工具副作用分类和高风险确认流程。

## 范围

### 后端

- `GET /api/v1/platforms/{platform_id}/mcp-servers`：分页返回服务列表。
- 保留 `POST /.../mcp-servers` 创建接口。
- `PATCH /api/v1/platforms/{platform_id}/mcp-servers/{server_id}`：更新名称、endpoint、认证头和 `is_active`。
- `DELETE /.../mcp-servers/{server_id}`：无审计时硬删除；有关联审计时返回冲突并要求停用。
- `GET /.../mcp-servers/{server_id}/tools`：返回已同步工具。
- 保留工具同步接口；保留工具策略 PATCH。
- `GET /.../agents/{agent_id}/mcp-servers`：查询绑定；保留绑定 PUT，新增解绑 DELETE。
- 保留 `GET /.../mcp-audits`，用于后台查看最近审计。
- 所有管理接口复用平台管理员校验；认证头不回显明文。

### 前端

- 重写 `/system/mcp-servers` 页面，增加平台选择。
- 服务列表、创建/编辑表单、启停开关、审计保护删除确认。
- 工具同步和工具策略编辑（允许调用、side effect）。
- 智能体绑定/解绑面板。
- 最近调用审计列表。
- 使用真实 `/platforms/{platform_id}/...` API，移除旧 `/api/mcp-servers` 调用。

## 非目标

- 不修改 MCP transport、远程客户端、确认流程和调用执行器。
- 不支持 stdio MCP 服务；沿用当前 HTTP/HTTPS endpoint 限制。
- 不提供认证头明文查看。
- 不删除有审计记录的服务或工具。

## 风险

- 同步工具会触发远程网络请求，页面需要显示 loading 和失败状态。
- endpoint、重定向和 DNS 校验必须由后端执行。
- 审计记录对服务/工具的 RESTRICT 外键决定删除语义，不能用无条件硬删除。

## 停点判断

- 架构边界变化：否。
- 数据模型变化：否，复用现有 MCP 表。
- API 契约变化：是，新增平台级管理、更新、删除保护、工具列表、绑定查询/解绑接口；进入实现前需人工确认。
- 鉴权或权限行为变化：否，复用平台管理员校验。
- 人工确认：是，尤其是审计保护删除语义。

## 验收标准

- OpenAPI 暴露 MCP 服务列表、更新、删除、工具列表、绑定查询和解绑接口。
- 非平台管理员不能访问 MCP 管理接口。
- 认证头不出现在任何响应明文中。
- 服务启停影响运行时工具可用性；工具策略影响允许调用和副作用确认。
- 有审计记录的服务删除被拒绝且不破坏审计；无审计服务可硬删除。
- 前端可完成服务 CRUD、同步工具、编辑工具策略、绑定/解绑智能体和查看审计。
- 后端定向测试/Ruff、前端 ESLint/Prettier 通过。
