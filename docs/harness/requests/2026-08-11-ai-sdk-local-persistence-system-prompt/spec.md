# 设计说明

## 目标

为 `apps/ai-sdk` 增加可持久化的本地聊天状态和真实生效的 `systemPrompt`：页面刷新后恢复消息列表及后端会话 ID，继续发送时保持同一会话上下文；清空本地聊天记录后下一次发送创建新会话。

## 范围

- `AgentClientOptions` 增加可选 `storageKey`，默认按平台、Agent 和用户隔离。
- SDK 初始化时从 `localStorage` 恢复 `messages` 和 `conversationId`，并在消息变更后自动保存。
- WebSocket transport 支持初始化和清空会话 ID；`message_send` 顶层及 payload 继续携带恢复的 `conversationId`。
- `message_send.payload` 增加可选 `systemPrompt`；后端网关将其传给会话运行时并与基础系统提示词合并。
- 新增 `clearLocalHistory()`，清除本地缓存、内存消息和会话 ID；保留连接可用，下一条消息开始新会话。
- 更新 SDK README、客户端/传输层测试和后端网关/运行时测试。

## 非目标

- 不新增数据库表、字段或迁移。
- 不把 SDK 本地完整历史作为后端模型上下文来源。
- 不改变鉴权、会话归属校验和后端历史时间窗口。
- 不做跨设备同步、摘要记忆或 token 级历史裁剪。

## 风险

- WebSocket 请求契约和后端运行时参数发生向后兼容的可选字段扩展。
- 浏览器存储异常、旧版本缓存和超长消息可能导致缓存被忽略或写入失败。
- system prompt 会影响模型行为；后端必须把它当作不可信调用方输入并保留基础 Agent 约束。

## 停点判断

- 架构边界变化：否
- 数据模型变化：否
- API 契约变化：是，`message_send` 增加可选 `systemPrompt`，进入实现前需人工确认
- 鉴权或权限行为变化：否
- 人工确认：用户已于 2026-08-11 确认推荐设计。

## 验收标准

- 首次初始化无缓存时行为与现有 SDK 一致。
- 初始化可恢复合法缓存中的消息和 `conversationId`；非法缓存被忽略且不阻塞初始化。
- 新增用户消息、助手完成消息和错误消息后会尝试保存缓存；存储失败不影响发送和展示。
- 刷新后首次发送包含恢复的 `conversationId`，后端继续加载同一会话历史。
- 每次 `message_send` 在有值时包含 `systemPrompt`，后端模型收到合并后的系统提示词。
- `clearLocalHistory()` 清空消息与本地会话 ID；清空后发送不再携带旧会话 ID。
- SDK 定向测试、类型检查、构建和后端网关/运行时测试通过。
