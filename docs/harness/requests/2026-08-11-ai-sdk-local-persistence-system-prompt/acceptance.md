## 剩余风险

- localStorage 属于同源页面可读存储，接入方不应把 token、密钥或高敏感内容放入消息元数据。
- 未提供 `user.id` 时默认使用 `anonymous` 隔离段；同一浏览器存在多身份切换的接入方应设置稳定的 `user.id` 或自定义 `storageKey`。
- 本次验证未连接真实模型，systemPrompt 的模型效果仍需部署环境按具体 Agent 做人工联调。
