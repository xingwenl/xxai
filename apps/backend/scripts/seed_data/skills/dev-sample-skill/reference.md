# 参考：整理文本的边界情况

这个文件只在 SKILL.md 不足以处理当前输入时读取，属于「渐进披露」的按需加载部分。

## 一段文本里有多个独立话题

按话题切分后各自走一遍 SKILL.md 的流程，最后合并成一份输出，用二级标题区分话题。
不要为了套用单一格式而把不相关的内容强行并成一条要点。

## 输入是纯列表

原文已经是列表时，重点是**去重与合并同级项**，不要逐条重写。合并后条数变少是正常的。

## 输入带明确的时间或责任人

这类信息一律进「待办」，并保留原文写法（不要把「下周三」换算成具体日期）。

## 输入是代码或日志

只整理「发生了什么」与「下一步查什么」，不要整理代码本身，也不要在输出里粘贴大段原文。
